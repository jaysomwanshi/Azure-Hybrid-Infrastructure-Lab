# 📖 Overview

This lab demonstrates how to create an Azure Virtual Network (VNet), configure multiple subnets, and understand Azure networking fundamentals including IP addressing, subnetting, and Azure's built-in Layer 3 routing.

---

# 🎯 Objectives

- Create Azure Virtual Network
- Configure Address Space
- Create Multiple Subnets
- Understand CIDR Notation
- Learn Azure Layer 3 Routing

---

# 🛠 Azure Services Used

- Azure Resource Group
- Azure Virtual Network
- Azure Subnets

---

# 🌐 Network Configuration

| Resource | Configuration |
|----------|---------------|
| Address Space | 192.168.10.0/24 |
| Servers Subnet | 192.168.10.0/26 |
| Clients Subnet | 192.168.10.64/26 |
