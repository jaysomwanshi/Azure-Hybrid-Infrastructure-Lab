## 📖 Overview

In this lab, I explored **Microsoft Entra ID (formerly Azure Active Directory)** and learned the fundamentals of cloud identity management. I created cloud users, configured security groups, explored device management, and reviewed enterprise applications and app registrations to understand how organizations manage identities in Microsoft Azure.

## 🎯 Objectives

- Understand Microsoft Entra ID
- Create cloud users
- Create security groups
- Add members to groups
- Explore device management
- Review Enterprise Applications
- Review App Registrations
- Understand Hybrid Identity architecture

## 🏗️ Architecture

```text
Microsoft Entra ID
        │
Cloud Identities
        │
Cloud Users + Security Groups
        │
Hybrid Identity
        │
Windows Server Active Directory
        │
Domain Computers
```
